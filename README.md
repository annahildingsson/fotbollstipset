# Fotbadskollen
A web-based project for managing and displaying "Stryktipset" (football betting) rows with dynamic interactivity using JavaScript.

## About the project
This project is part of a JavaScript examination where the goal is to build an interactive betting page for football enthusiasts. The application loads matches and dynamically generates the betting slip within the HTML table, handling interactions such as selecting match outcomes (1, X, 2).

## Features

- **Dynamic table:** Generates betting rows and matchups directly via JavaScript.
- **Interactive choices:** Ability to select outcomes (1, X, 2) utilizing custom checkmarks.
- **Modular code:** Structured with ES modules (`import`/`export`) for clean and maintainable logic.
- **Responsive layout:** Adaptive design for seamless use across various screen sizes.
